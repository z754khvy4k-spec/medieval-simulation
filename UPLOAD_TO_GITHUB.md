# GitHub Pages Upload

This folder is the complete deployable version of the simulation.

Upload the CONTENTS of this folder to the root of your GitHub repository:

- index.html
- README.md
- manifest.webmanifest
- sw.js
- assets/ (keep this folder intact)

If using GitHub's web interface, drag the entire contents of this folder into the repository's upload area. The `assets` folder will be preserved automatically.

Do not upload the ZIP itself as the website.
